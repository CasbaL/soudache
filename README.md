# 仙侠搜打撤

移动端仙侠题材生存建造游戏，核心循环为搜打撤（Search-Fight-Extract）。

## 游戏特色

- **搜打撤核心循环**：搜刮资源 → 战斗敌人 → 撤离保留物资
- **仙侠题材**：水墨渲染 + 赛博光效的视觉风格
- **建造系统**：洞府建造，提供长期目标
- **装备系统**：5种稀有度，强化、套装系统
- **3层地图**：幽竹林、火焰山、天机阁

## 技术栈

- **引擎**: Godot 4.2
- **语言**: GDScript
- **平台**: iOS / Android

## 项目结构

```
game/
├── assets/          # 游戏资源
├── data/            # 游戏数据（JSON）
├── docs/            # 设计文档
├── scenes/          # Godot 场景
├── scripts/         # GDScript 脚本
└── project.godot    # 项目文件
```

## 快速开始

### 1. 安装 Godot 4.2

下载地址: https://godotengine.org/download

### 2. 打开项目

1. 启动 Godot 4.2
2. 点击"导入"按钮
3. 选择 `game/project.godot` 文件
4. 点击"导入并编辑"

### 3. 运行游戏

1. 按 `F5` 或点击"运行"按钮
2. 游戏将在测试关卡中启动

### 4. 操作说明

| 操作 | 按键 |
|---|---|
| 移动 | W/A/S/D |
| 技能1 | 1 |
| 技能2 | 2 |
| 技能3 | 3 |
| 闪避 | 空格 |

## 核心系统

### 搜打撤循环

1. **搜刮**：探索地图，收集灵石、灵草、矿石等资源
2. **战斗**：击败敌人，获得经验和掉落物
3. **撤离**：到达撤离点，保留当前物资

### 建造系统

- **炼丹炉**：炼制丹药，提供战斗buff
- **炼器台**：打造装备，提升战斗力
- **修炼室**：提升境界，解锁新能力
- **藏经阁**：学习功法，获得新技能
- **灵田**：种植灵草，被动产出资源

### 装备系统

- **5种稀有度**：凡品（白）→ 灵品（绿）→ 宝品（蓝）→ 仙品（紫）→ 神品（金）
- **强化系统**：+1到+15，成功率递减
- **套装系统**：3件套，提供额外效果
